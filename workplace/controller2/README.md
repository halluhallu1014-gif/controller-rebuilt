# コントローラー2の会社導入

[貼り付け用Rawコード](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/controller2/InstallController2.txt)

## 導入手順

1. 会社で設定済みのコントローラー2.xlsmを複製し、元のブックを閉じます。作業コピーをデスクトップ版Excelで開き、操作画面とカレンダーを閉じます。VBAプロジェクトのロックが解除され、組織のポリシーでマクロ実行とVBAプロジェクト オブジェクト モデルへのアクセスが許可されている必要があります。
2. Alt + F11 →「挿入」→「標準モジュール」を選びます。F4でモジュールの (Name) を Controller2Setup に変更し、Raw本文全体を1回貼り付けます。
3. Alt + F8で InstallController2 を実行し、ステータスバーに Controller2 install complete が出ることを確認します。エラーが出た場合は作業コピーを保存せず閉じます。
4. VBEの「デバッグ」→「VBAProjectのコンパイル」を実行します。導入後の構成は20コンポーネントと導入用モジュールです。導入用モジュールは実行完了後に削除できます。削除した場合はもう一度コンパイルします。
5. Address、Fields、Operationsの3シートと設定を確認し、作業コピーを保存します。会社の検証用ブックでは、開き直して検索・詳細・再読込み・終了を確認してから運用へ切り替えます。検証中に同期やバックアップを動かす場合は、検証用管理簿と保存先を指定した別コピーを使用してください。

導入コードは3シートの存在を確認して、各シートのコードモジュールを入れ替えます。シートのセル、設定値、シート名、書式はそのまま保持します。VBEのファイルインポートやフォームの手組みは不要です。

## SharePoint

会社で設定済みの直接HTTPS URLを引き継ぎます。Addressではフォルダの直接HTTPS URLと拡張子付きファイル名を組み合わせます。Operationsのログ・バックアップには専用ブックの直接HTTPS URLを、復旧ジャーナルには専用フォルダの直接HTTPS URLを使用します。既存の転記前の排他確認、操作ログと日次バックアップのチェックアウト・チェックイン、保存後の確認と復旧の手順を引き継ぎます。
