# CONTROLLER 会社用の新規構築

Windows デスクトップ版 Excel の空ブック2冊から構築します。会社のマクロ利用ルールに従ってください。

## 1. 本体を構築

1. [VBAインポート用ZIP](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/CONTROLLER-VBA.zip) を取得し、展開します。
2. Excelで新規ブックを作り、ワークシート1枚だけの空の状態で `CONTROLLER.xlsm` として保存します。
3. Alt+F11 でVBEを開き、対象ブックのプロジェクトを選びます。「ファイル」→「ファイルのインポート」で、ZIPの `main` 内の `.bas` と `.cls` をすべて取り込みます。
4. 既存の `ThisWorkbook` を開き、[本体のイベントコード](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/main/ThisWorkbook.txt) の全文をコピーします。VBEの ThisWorkbook で Ctrl+A を押し、既存コードを全文置き換えます。「デバッグ」→「VBAProjectのコンパイル」を実行します。
5. Excelに戻り、Alt+F8 から `InstallControllerMain` を実行します。構築と構成確認の完了メッセージ、および「検索」「詳細」シートを確認して保存し、閉じます。

## 2. 設定ツールを構築

1. ワークシート1枚だけの空ブックを `CONTROLLER設定.xlsm` として、本体と同じフォルダに保存します。
2. VBEで設定ツールのプロジェクトを選び、ZIPの `setup` 内の `.bas` と `.frm` をすべて取り込みます。フォームの `.frx` は同名の `.frm` の横に置いたままにします。
3. 既存の `ThisWorkbook` に [設定ツールのイベントコード](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/setup/ThisWorkbook.txt) の全文をコピーします。VBEの ThisWorkbook で Ctrl+A を押し、既存コードを全文置き換えてコンパイルします。
4. Excelで `InstallControllerSettings` を実行します。構築完了メッセージと「設定を開く」ボタンを確認し、保存します。

## 3. 初期設定と起動

### 現行の設定ツール

1. 本体を閉じ、CONTROLLER設定.xlsm の「設定を開く」を押します。同じフォルダに本体がない場合は「本体を選択」で指定します。
2. ホームの案内に従い、常勤（Staff）、非常勤（General）、退避（Backup）の行を選び、「フォルダを選択」を押します。同一SharePointサイト内の異なる3フォルダを指定し、管理簿.xlsmは常勤・非常勤の片方だけに置きます。選択画面から指定できないときは、直接URLを入力します。
3. 「変更を保存」を押します。途中でも保存でき、設定を開き直すと保存した値が戻ります。担当者が未登録の場合は、本体を書き込める現在のWindowsアカウントを初回保存時に登録します。共有先では、本体への書込権限も担当者に限定してください。
4. ホームで使用開始の案内を確認し、設定ツールを閉じます。本体の「最新を再読込」で管理簿を確認します。SharePointの接続は本体で確認してください。
5. 自宅などで移動を使わず管理簿1冊を使用する場合は、「管理簿の個別指定」でローカルファイルを選択できます。シートや年度を指定するときは「年度を確認」、列の対応を修正するときは「見出しと対応」を使います。

試験用のSharePointフォルダと架空データの管理簿を指定してください。最初は検索と詳細表示を確認します。本番管理簿の登録・更新や移動は行いません。


## 復旧

- 両フォルダに管理簿がある、または両方にない場合は、現在地を確認してから再読込します。
- 保存・移動結果が未確定の場合は操作を繰り返さず、本体の確認機能と管理簿・退避先の状態を照合します。
- 構築時にエラーが出た場合は、そのブックを保存せず閉じ、正しい部品と貼付先を確認して空ブックからやり直します。

## 検証範囲

この版の配布部品からWindows版Excelで空ブック2冊を構築しました。カレンダーボタンは現行仕様どおり未接続です。会社のSharePoint認証・アクセス権と実際の動作は試験用の環境で確認してください。
