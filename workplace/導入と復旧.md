# CONTROLLER 会社用の新規構築

Windows デスクトップ版 Excel の空ブック2冊から構築します。会社のマクロ利用ルールに従ってください。

## 1. 本体を構築

1. [VBAインポート用ZIP](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/CONTROLLER-VBA.zip) を取得し、展開します。
2. Excelで新規ブックを作り、ワークシート1枚だけの空の状態で `CONTROLLER.xlsm` として保存します。
3. Alt+F11 でVBEを開き、対象ブックのプロジェクトを選びます。「ファイル」→「ファイルのインポート」で、ZIPの `main` 内の `.bas` と `.cls` をすべて取り込みます。
4. 既存の `ThisWorkbook` を開き、[本体のイベントコード](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/main/ThisWorkbook.txt) の全文を貼り付けます。「デバッグ」→「VBAProjectのコンパイル」を実行します。
5. Excelに戻り、Alt+F8 から `InstallControllerMain` を実行します。構築と構成確認の完了メッセージ、および「検索」「詳細」シートを確認して保存し、閉じます。

## 2. 設定ツールを構築

1. ワークシート1枚だけの空ブックを `CONTROLLER設定.xlsm` として、本体と同じフォルダに保存します。
2. VBEで設定ツールのプロジェクトを選び、ZIPの `setup` 内の `.bas` と `.frm` をすべて取り込みます。フォームの `.frx` は同名の `.frm` の横に置いたままにします。
3. 既存の `ThisWorkbook` に [設定ツールのイベントコード](https://raw.githubusercontent.com/halluhallu1014-gif/controller-rebuilt/main/workplace/setup/ThisWorkbook.txt) の全文を貼り付け、コンパイルします。
4. Excelで `InstallControllerSettings` を実行します。構築完了メッセージと「設定を開く」ボタンを確認し、保存します。

## 3. 初期設定と起動

1. 本体を閉じ、「設定を開く」でStaff、General、Backupを指定します。選択ダイアログを使い、SharePointの直接URLを選択できない場合はダイアログを閉じて手入力を選びます。3フォルダは同一SharePointサイト内の異なる場所を指定します。
2. `管理簿.xlsm` はStaff・Generalの片方だけに置きます。管理簿の1行目は見出し、年度を表すシート名は `2026` などとします。サイトURL・管理簿の直接URL・年度の追加入力は通常不要です。
3. 「設定を保存」し、設定ツールを閉じます。以後は本体の「最新を再読込」で管理簿を自動検出します。検索結果を選択して詳細表示を確認します。新規登録や更新は検証用管理簿で先に確認します。
4. 職場で朝夕の移動を実行する場合は、常勤フォルダから本体を起動します。移動ボタンは現在地に応じて切り替わります。

## 復旧

- 両フォルダに管理簿がある、または両方にない場合は、現在地を確認してから再読込します。
- 保存・移動結果が未確定の場合は操作を繰り返さず、本体の確認機能と管理簿・退避先の状態を照合します。
- 構築時にエラーが出た場合は、そのブックを保存せず閉じ、正しい部品と貼付先を確認して空ブックからやり直します。

## 検証範囲

自宅のWindows版Excelで、空ブック2冊からの構築、3フォルダ設定と復元、1,000件の検索・詳細表示、新規登録・更新・保存・再読込を確認しました。職場のSharePoint認証・権限・サーバー操作は実環境で確認してください。
