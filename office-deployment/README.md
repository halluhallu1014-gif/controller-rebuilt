# 6ファイル進捗整理簿：会社導入用

このディレクトリは、会社PCで **GitHub Rawからコピー＆貼付**して導入するためのVBAソースです。
ソースはUTF-8でGitHubに掲載し、会社PCのVBEへコード本文をコピーする方式を推奨します。 `.bas` のファイルインポートを行うときはCP932に変換してください。

## 1. 会社側で空の操作ブックを作る

1. Excelを新規起動し、空のブックを `コントローラー.xlsm` として保存します。
2. Alt+F11 → 挿入 → 標準モジュール。 `BuildOfficeController.bas` の **Attribute VB_Name行を除くコード本文** を貼り付けます。
3. `BuildOfficeController` を実行します。4枚のシート（検索、詳細、Address、Sheet2）が作成されます。
4. 「Address」シートのB2:B8に**会社環境で使うフォルダパス**を入力します。C列はファイル名で、C2だけ空欄。SharePointでは実際に開けるURLを入力します。
5. 他の `.bas` と `CaseRecord.cls` を各モジュールへ貼り付けます。**CaseRecordはクラスモジュール**を新規作成し、名前を `CaseRecord` に変更してください。
6. ［デバッグ］→［VBAProjectのコンパイル］を実行します。
7. 既に実運用中の進捗整理簿がある場合、`CreateEmptyLedgers` は実行しません。

## 2. 管理簿ファイルの作成

新規導入かつ保存先がローカルの場合、 `Address` のB3:B8に存在するフォルダパスを設定して `CreateEmptyLedgers` を実行すると、全体（48列）1冊と署別（D列が○の項目だけ）5冊の空の `.xlsx` ができます。既存ファイルは上書きしません。

SharePointのURL保存先では、作成したローカルの空の `.xlsx` を各SharePointフォルダへ手動配置してください。`Dir` をURLに対して使うことはできないため、 `CreateEmptyLedgers` は **ローカルフォルダ用**です。

## 3. 実行ボタン

- 一般事務整理簿の新規取込: `ImportWeeklyLedger`
- 全体から5署へ転記更新: `TransferToFiveOffices`
- 氏名検索: `SearchCases`
- 詳細表示: `ShowSelectedCaseDetail`
- 全体への保存: `SaveCurrentCase`
- 前ページ: `SearchPreviousPage`、次ページ: `SearchNextPage`

## 4. 仕様と運用注意

- `Address` A列=識別名、B列=**個別フォルダを含むパス**、C列=ファイル名（拡張子なし）。
- `Sheet2` A列=項目名、B列=全体管理簿列、C列=詳細表示セル、D列=5署へ転記(○/×)。
- 週次取込は見出し名を基準に列を対応付ける。元ファイル名を「元ファイル」に記録。
- 署別ファイルへ転記しない6項目（メモ1～3、発送1～3）はD列を×にする。
- 正本は進捗整理簿【全体】。通常更新は全体へ保存し、署別は転記ボタンで同期。
- `TransferEngine` は全体ファイル内に「転記基準」シートを作り、転記済みとの差分を判断します。
- 初回は架空のサンプルでテストしてください。 **会社の本番データをGitHubにアップロードしない** でください。

## 5. テスト順序

コンパイル → 全体読込 `TestLoadMasterRecords` → 検索 → 詳細表示 → 変更なし保存 → 1項目だけ更新 → 一般事務整理簿取込 → 5署への転記。

この配布版は、会話内で単体テストを通過した処理をベースにしていますが、**会社のOffice/SharePoint環境での実機試験は未実施**です。特にURLでのSaveAsや既存マクロとの衝突は会社側で確認が必要です。
